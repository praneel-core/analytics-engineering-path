# Analytics Engineering Path

A hands-on learning path for **Analytics Engineer / dbt Developer** roles, built around SQL practice on Databricks Free Edition.

## Contents

| Folder | Description |
|---|---|
| [`sql/`](sql/) | Complete SQL practice lab: a realistic e-commerce dataset (14 tables, ~700k rows), 250 questions with hints but no answers, a concepts reference, and a progress tracker. |

## Start here

1. Open [`sql/README.md`](sql/README.md) for the full guide.
2. Import `sql/01_setup_ecommerce_lab.py` into Databricks and run it on Serverless to build the dataset.
3. Import `sql/02_sql_practice_250_questions.ipynb` and work through the questions in order.
4. Track progress in `sql/04_sql_learning_tracker.md`; use `sql/03_sql_analytics_engineering_reference.md` to revise concepts.

More modules (dbt projects, modelling exercises) can be added alongside `sql/` as the path grows.
